Embedded Systems Laboratory Experiments

This submission contains a set of six embedded systems experiments implemented using the STM32 NUCLEO-F446RE development board. The experiments cover fundamental concepts such as GPIO control, PWM, UART communication, I2C interfacing, and multitasking using FreeRTOS.

Hardware Used
STM32 NUCLEO-F446RE Board
OLED Display (SSD1306 – I2C)
USB Cable
PC/Laptop

Software Used
STM32CubeIDE
STM32CubeMX
TeraTerm / PuTTY (for UART communication)

Each experiment is organized into separate folders as shown below:

Experiment_1 → LED Toggle
Experiment_2 → LED Brightness Control (PWM / Delay)
Experiment_3 → UART Transmission
Experiment_4 → UART Reception with Password Validation
Experiment_5 → I2C Interface with OLED Display
Experiment_6 → FreeRTOS (Multitasking with LED & UART)

Each experiment folder contains:

Project files (CubeIDE project)
Source code
Output images/screenshots
Report explaining procedure and results

These experiments provide hands-on experience in embedded systems programming and demonstrate practical implementation of communication protocols and real-time operating systems using STM32 microcontrollers.
